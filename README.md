# GATE O ID — Premium Affiliate Hub

Website katalog produk affiliate dengan admin panel. Bahasa Indonesia. Zero build step.

## Fitur
- 🛍️ Katalog produk dengan filter kategori & search
- 📊 Tracking klik per produk
- 🔐 Admin panel dengan login (client-side)
- 💾 Export / import data JSON / CSV
- 🌙 Dark theme
- 📱 Responsive
- 🔒 XSS-protected (escapeHtml di semua output)

## Akses Admin
- **URL Admin:** `admin.html`
- **Password Default:** `gateo2025` (dapat diubah di `js/config.js`)
- **Catatan Login:** Jika mengalami kendala saat login, pastikan untuk menghapus sesi lama atau melakukan *hard refresh* (Ctrl + F5 / Cmd + Shift + R) agar file konfigurasi terbaru termuat dengan benar.
